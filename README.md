Data Analysis for a taxi Company

This program determines if there is a significant difference in the average tip when customers take a yellow cab versus a green cab. (There are two different colors of taxis in New York.) We have data with ride information. We will use 2-sample t-test to perform the evaluation.

The data comes from a taxi cab company in New York City.

To Run it:
1. Open the program GenBus881_Assignment_4_Taxi_Data_Natarajan_K.ipynb in GitHub
2. Click the 'Open in Colab' button at the top
3. Click 'Run All'
